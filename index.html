連接 GitHub 儲存庫

密碼庫的加密資料會存放在你的 Private GitHub repo，程式本身不會另外傳送資料到任何地方。

Token 需要具備此 repo 的 Contents 讀寫權限（Fine-grained token → Only select repositories → Contents: Read and write）。帳號、repo 名稱與路徑會存在這台裝置的瀏覽器中方便下次使用，但 Token 不會被儲存。

建立密碼庫

這個 repo 裡還沒有密碼庫，設定一組主密碼來建立一個新的。

主密碼不會被儲存在任何地方，只用來解鎖資料。忘記主密碼時可用 Recovery Key 重設（下一步會產生），但兩者都遺失將無法復原資料。
